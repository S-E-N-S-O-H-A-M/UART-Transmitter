UART Transmitter — Design & Verification Document

This document describes a simple, configurable UART transmitter (uart_tx) implemented in SystemVerilog, along with a self-checking testbench (uart_tx_tb).

1 Overview

  • Protocol: Standard asynchronous UART — 1 start bit, 8 data bits (LSB first), 1 stop bit, no parity.
  • Configurable baud rate: Set via two parameters (CLK_FREQ, BAUD_RATE). The module automatically computes the required clock divider.
  • Interface: Simple valid/ready-style — pulse tx_start with data, monitor tx_busy/tx_done.
  • Technology: Pure RTL, no vendor primitives. Synthesisable on any FPGA or ASIC target.

The internal divider is computed as: CLKS_PER_BIT = CLK_FREQ / BAUD_RATE. Ensure the clock frequency is an integer multiple of the baud rate for zero-error timing.

7 Design Source Code

File: rtl/uart_tx.sv

// UART Transmitter — configurable baud rate
module uart_tx #(
    parameter CLK_FREQ  = 50_000_000,
    parameter BAUD_RATE = 115_200
)(
    input  logic       clk,
    input  logic       rst_n,
    input  logic [7:0] tx_data,
    input  logic       tx_start,
    output logic       tx_out,
    output logic       tx_busy,
    output logic       tx_done
);

    localparam integer CLKS_PER_BIT = CLK_FREQ / BAUD_RATE;

    typedef enum logic [2:0] {
        S_IDLE  = 3'b000,
        S_START = 3'b001,
        S_DATA  = 3'b010,
        S_STOP  = 3'b011,
        S_DONE  = 3'b100
    } state_t;

    state_t              state;
    logic [$clog2(CLKS_PER_BIT)-1:0] baud_cnt;
    logic [2:0]          bit_idx;
    logic [7:0]          tx_shift;

    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state    <= S_IDLE;
            tx_out   <= 1'b1;
            tx_busy  <= 1'b0;
            tx_done  <= 1'b0;
            baud_cnt <= '0;
            bit_idx  <= '0;
            tx_shift <= '0;
        end else begin
            tx_done <= 1'b0;

            case (state)
                S_IDLE: begin
                    tx_out  <= 1'b1;
                    tx_busy <= 1'b0;
                    if (tx_start) begin
                        tx_shift <= tx_data;
                        tx_busy  <= 1'b1;
                        state    <= S_START;
                        baud_cnt <= '0;
                    end
                end

                S_START: begin
                    tx_out <= 1'b0;
                    if (baud_cnt == CLKS_PER_BIT - 1) begin
                        baud_cnt <= '0;
                        bit_idx  <= '0;
                        state    <= S_DATA;
                    end else
                        baud_cnt <= baud_cnt + 1;
                end

                S_DATA: begin
                    tx_out <= tx_shift[bit_idx];
                    if (baud_cnt == CLKS_PER_BIT - 1) begin
                        baud_cnt <= '0;
                        if (bit_idx == 3'd7)
                            state <= S_STOP;
                        else
                            bit_idx <= bit_idx + 1;
                    end else
                        baud_cnt <= baud_cnt + 1;
                end

                S_STOP: begin
                    tx_out <= 1'b1;
                    if (baud_cnt == CLKS_PER_BIT - 1) begin
                        baud_cnt <= '0;
                        state    <= S_DONE;
                    end else
                        baud_cnt <= baud_cnt + 1;
                end

                S_DONE: begin
                    tx_done <= 1'b1;
                    tx_busy <= 1'b0;
                    state   <= S_IDLE;
                end

                default: state <= S_IDLE;
            endcase
        end
    end

endmodule

8 Testbench

Verification Strategy

  • Self-checking: Each transmitted frame is captured by sampling tx_out at the midpoint of each bit period, then compared against the expected {stop, data, start} pattern.
  • Test 1 — Idle Check: Verifies tx_out is high and tx_busy is low after reset.
  • Test 2 — Known Patterns: Sends 0x00, 0xFF, 0xA5, 0x5A, 0x0F, 0xF0, 0x55, 0xAA — covering all-zeros, all-ones, alternating, and boundary patterns.
  • Test 3 — Random Data: 16 random bytes via $urandom.
  • Test 4 — Back-to-back: 4 consecutive transmissions with no idle gap to stress the FSM re-entry path.
  • Timeout watchdog: Kills simulation if it hangs.

11 Design Considerations

  • Baud rate accuracy: Integer division means some baud rates will have rounding error. For 50 MHz / 115200 = 434.03 → 434 (0.007% error, well within UART tolerance of ±2%).
  • Asynchronous reset: Used for compatibility with FPGA global reset networks. Can be changed to synchronous reset by removing or negedge rst_n from the sensitivity list.
  • No parity: The most common configuration (8N1). Parity can be added by inserting an extra state between S_DATA and S_STOP.
  • Resource usage: ~25 FFs, ~40 LUTs on a typical FPGA — negligible.
